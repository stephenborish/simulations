    Post-lab Q1

    Same DNA… or not?

    Banana DNA and your DNA looked the same in the tube. Zoom in to compare their code.

    The same in every living thing

    • Double helix (twisted ladder) shape
    • Same 4 bases: A, T, C, G
    • Same sugar-phosphate backbone
    • Looks white and stringy when extracted

    Different between sources

    • The order of the bases (the code / genes)
    • How much DNA there is
    • Number of chromosomes (banana 33, human 46)
